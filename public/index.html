1. Guided local setup

Install Python and Node.js. In your downloaded project folder, run:

python scripts/setup_ui.py

2. Prepare dedicated Aiven database

Use the existing Aiven PostgreSQL service only after confirming a dedicated database or appropriate isolation. Paste the connection URL only into your local setup or Vercel environment settings.

PGDATABASE="$DATABASE_URL" psql -X -v ON_ERROR_STOP=1 -f scripts/schema.sql

3. Deploy web dashboard

npx vercel --prod

Set DATABASE_URL and ADMIN_API_KEY as encrypted Vercel project environment variables. Do not commit .env.local.

4. Start optional image analysis

pip install -r requirements-worker.txt

5. Run tests

npm test && pytest tests/test_detector.py

Go to Add New → Project, select Simmyt3r/RSCDS-Project, and import. Choose Other for Framework Preset, ./ for Root Directory, and public for Output Directory. The repository provides npm run build automatically in vercel.json.

03

Add secrets using Vercel's Settings UI

Open Project → Settings → Environment Variables. Create the following variables in Production before deployment. Use encrypted/sensitive fields and the Aiven PostgreSQL URI with SSL enabled.

DATABASE_URLAiven PostgreSQL connection string, server-side onlyADMIN_API_KEYA unique, strong administrator secret, server-side onlyWORKER_API_KEYDifferent secret for the satellite queue worker

This generator never sends or stores the secret. Generate separate values for ADMIN_API_KEY and WORKER_API_KEY. Copy each to Vercel's sensitive environment-variable fields. Put only the WORKER_API_KEY in GitHub Actions Secrets.

04

Deploy from the Vercel interface

Click Deploy in Vercel. If you added environment variables after your first deployment, use the Redeploy action from the Vercel Deployments tab. Copy your website URL when it becomes Ready.

Open deployment dashboard ↗
Run the check after deploying. The diagnostic never displays stored secrets.
05

Enable the protected GitHub worker

Under repository Settings → Secrets and variables → Actions, add variable RSCDS_DEPLOY_URL (HTTPS Vercel app origin) and secret RSCDS_WORKER_API_KEY (matches the distinct WORKER_API_KEY stored in Vercel). Queue jobs from the RSCDS satellite imagery screen. GitHub Actions checks automatically every 30 minutes, or you can press Run workflow with no location inputs. No candidate-location artifacts are uploaded.

GitHub secrets ↗Run analysis ↗
A public GitHub repository can expose workflow activity and dependency behavior. Use a private repository and trusted worker for sensitive or humanitarian study areas. Never paste coordinates into public CI inputs or logs.

Privacy and operational limits

This is a research-grade change-candidate detector, not a trained or independently validated temporary-settlement classifier. Do not publicize sensitive locations, publish raw GeoJSON, or infer population/displacement from pixels. Satellite analysis remains a separate worker, not a serverless web request.
